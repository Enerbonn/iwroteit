# Iwroteit Ink

Iwroteit Ink is an OFL-licensed derivative of the bundled Shantell Sans font.
Original copyright: 2022 The Shantell Sans Project Authors.
See OFL.txt for the full license; the original font is kept unmodified.

The derivative is renamed Iwroteit Ink. It adds 32 addressable generated glyphs
for each ASCII letter and digit, based on the available original glyph forms,
plus a new INKR axis that applies a smooth seeded deformation to their outline
and curve-control points. These are generated contour variations, not 32
independently hand-drawn originals. It does not synthesize tablet pen paths.
Composite glyphs, such as dotted letters, vary component placement.

Rebuild with scripts/build_ink_font.py and fonttools (development dependency
only). The font is bundled, so ordinary document creation needs no fonttools.
